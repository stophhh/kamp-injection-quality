# 로컬 데이터 준비

이 폴더의 데이터는 공개 저장소에 포함하지 않습니다. 정당한 사용 권한을 가진 파일만 로컬에서 배치하세요.

검증: `cn7_final.csv`, `rg3_final.csv`, `moldset_labeled.csv`.
추론 추가 입력: `moldset_unlabeled_cn7.csv`, `moldset_unlabeled_rg3.csv`, `unlabeled_data.csv`.

원본 제출 ZIP의 dataset/ 파일은 이 폴더에 배치합니다. 파일 내용·행 순서는 변경하지 않습니다.
`cn7_final.csv`와 `rg3_final.csv`는 제출 시 사용한 메타정보 결합본입니다.
가공 파일과 원천 파일의 연결 과정은 원본 첫 셀에 일부 있으나 RG3의 고정 offset(+214),
폴더 경로 차이, 작업 변수 연결이 있어 원천부터 완전한 생성 절차로 검증되지 않았습니다.
본 공개본은 제출된 final CSV를 시작점으로 사용합니다.

주요 컬럼: 공정 24개, PassOrFail(0 정상/1 불량), _id, TimeStamp, Side.
Reason은 사후 분석용이며 모델 입력에 포함하지 않습니다.
제품/설비 식별정보와 행 단위 레코드는 공개하지 않습니다.

미라벨 가공 파일의 Unnamed: 0은 원천 unlabeled_data.csv의 행 위치(iloc)입니다.
원천 행을 정렬하거나 부분 추출하면 연결이 달라집니다. 공식 새 버전 파일을 임의로 대체하지 마세요.

출처는 KAMP 사출성형 관련 제공 자료입니다. 정확한 배포 버전, 데이터셋 원문 링크,
가공·재배포 조건은 보유 가이드와 이용약관을 확인한 뒤 보완해야 합니다.
공개본에 데이터를 넣지 않았다는 사실만으로 노트북·그래프 등 모든 산출물의 공개 허용이 확정되지는 않습니다.
