# 실험과 선택 근거

원본 노트북의 저장 출력에서 확인한 기록입니다. 실험은 이번 공개 정리 과정에서 재실행하지 않았습니다.

| CN7 비교 | AP | Top5% Recall | Top10% Recall |
|---|---:|---:|---:|
| 기본 공정 LogReg | 0.340 | 0.647 | 0.765 |
| 기본 공정 RF | 0.402 | 0.647 | 0.882 |
| 기본 공정 XGBoost | 0.325 | 0.471 | 0.882 |
| RF + ExtraTrees 결합 실험 | 0.470 | 0.588 | 0.941 |
| ExtraTrees + Cyclic Hour | 0.518 | 0.765 | 0.941 |
| ExtraTrees + Cyclic Hour + Delta 4개 | 0.522 | 0.824 | 0.941 |

여러 실험을 거쳐 마지막 구성을 최종 선택했습니다. RF+ExtraTrees 결합은 최종 모델이 아닙니다.
시간변수 구성 대비 Delta 추가의 Top5% 변화는 불량 13→14건으로 한 건입니다.
시간대와 불량의 연관을 원인 관계로 해석하지 않습니다.

원본에는 Random Over/Under Sampling, SMOTE, 원천 비율·상호작용,
RG3 Delta·Rolling·RH-only·Shot-level, 기상자료 비교 실험도 있습니다.
기상 특징은 최종 모델에 포함되지 않습니다. 개인 API 키나 외부 API가 이 공개본에 필요하지 않습니다.
모든 후보의 우열을 재현 확인한 것으로 주장하지 않습니다.

원본 전체 노트북은 행 단위 출력과 외부 API 실험, 변수 재정의가 있어 공개본에 포함하지 않았습니다.
공개본은 최종 검증·예측을 분리했고 입력 로딩, 누락 검사, 출력 경로를 추가했습니다.
모델 설정과 주요 특징 계산은 제출 당시 정의를 유지했습니다.
