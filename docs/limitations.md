# 검증 범위와 알려진 한계

## 저장된 결과와 재실행을 구분
README 수치는 submission.zip 안 kamp.ipynb의 저장 출력과 final CSV의 표본 수에 근거합니다.
공개용으로 정리한 두 노트북은 구문 검사를 수행했지만 실제 데이터로 재학습하지 않았습니다.
버전이 고정된 실행환경이 없어 결과의 완전 일치를 보장하지 않습니다.

## 검증과 일반화
- CN7은 TimeStamp 그룹 4-fold, shuffle=True, random_state=42의 OOF입니다. 날짜 순서 평가가 아닙니다.
- 같은 TimeStamp를 Shot으로 간주합니다. 실제 생산 Shot 식별의 완전성을 보장하지 않습니다.
- 여러 모델·특징을 같은 개발 검증에서 선택했으므로 선택 편향이 있습니다.
- RG3는 2020-10-23 이전 학습 682건/불량15건, 이후 평가 500건/불량10건입니다. 해당 구간을 여러 실험에서 보았으므로 독립 최종 시험으로 과장하지 않습니다.
- CN7 17건, RG3 평가10건의 소수 불량으로 계산한 결과입니다.
- 가공된 기본 공정변수의 스케일링 계보와 fold 내 적합 여부는 별도 확인이 필요합니다.
- 사후 불량 사유(Reason)는 모델 입력에서 제외합니다. 실제 입력 확정 시각과 검사 시각은 확인이 필요합니다.

## 학습·추론의 차이
CN7 학습 Hour는 dt.hour이고 미라벨 추론 Hour는 hour+minute/60+second/3600입니다.
공개 복사본은 제출 당시 수치를 다른 모델의 수치로 바꾸지 않기 위해 이를 명시적으로 보존했습니다.
수정 후에는 검증·추론을 함께 재실행하고 기존 결과와 별도로 기록해야 합니다.
Delta는 labeled와 unlabeled 각각에서 계산하며 첫 관측값을 0으로 둡니다.
관측 공백이나 기간 변경으로 실제 직전 사이클과의 변화량이 아닐 수 있습니다.

## Label Conflict의 해석
24개 공정 입력 기준 상충 그룹은 CN7 11개, RG3 25개입니다.
RG3 불량25건이 이 그룹에 포함되지만 Side를 추가하면 입력의 구별 가능성이 달라집니다.
따라서 모든 입력으로 구별 불가능하거나 라벨이 잘못되었다고 단정하지 않습니다.
RG3 불량이 모두 RH인 관측 사실도 다른 생산기간의 법칙으로 일반화하지 않습니다.

## 순위와 운영
Top-k 평가는 ceil(N*k)개를 선택합니다. 원본 평가의 동점은 NumPy 정렬에 의존합니다.
추론 Risk_Rank는 rank(method="first")로 기존 행 순서에 따라 동점을 나눕니다.
5% 경계의 선택 수와 동점 정책이 평가·추론에서 완전히 같지는 않습니다.
High/Medium/Low는 제품 내 상위5%/5~20%/나머지 구간이며 실제 불량 판정이 아닙니다.
CN7/RG3 점수는 공통 확률 척도가 아니며 검사 생략·자동 폐기의 근거가 아닙니다.
71,180건의 미라벨 추론은 적용 규모이며 성능 입증 자료가 아닙니다.
